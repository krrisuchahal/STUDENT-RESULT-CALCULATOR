# Project Statement

## Problem Statement

Calculating a student's result by hand — adding marks, working out the
percentage, and deciding the grade — is repetitive and can lead to
mistakes, especially when done for many students. This project
automates that process with a simple Python program.

## Scope of the Project

This is a **console-based Student Result &amp; Grade Calculator**. It
covers:

- Entering a student's marks in 5 fixed subjects
- Calculating total marks, percentage, and letter grade automatically
- Deciding pass/fail status based on overall percentage and minimum
  per-subject marks
- Viewing all results, searching by roll number, and viewing a class
  summary (pass/fail count and average)

It does not include multiple semesters, subject-wise rank, or a
graphical interface — these could be added later.

## Target Users

- A teacher or student who wants a quick way to calculate and store
  exam results without doing the maths by hand.

## High-Level Features

1. **Result Calculation** — enter marks, get total, percentage, grade,
   and pass/fail status instantly
2. **Record Keeping** — all student results are saved and can be
   viewed or searched later
3. **Class Summary** — see overall pass/fail counts and the class
   average percentage
